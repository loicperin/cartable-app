# Cartable · lanceur

Petite application web installable qui ouvre le Cartable dans sa propre fenêtre
(icône dans la barre des tâches, le Dock ou l'écran d'accueil).

Page d'installation : https://loicperin.github.io/cartable-app/

Ce dépôt est généré depuis le dossier `lanceur/` du projet Cartable : ne pas le modifier directement.
